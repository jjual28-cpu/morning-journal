⚙️ 설정

구글시트 자동 기록

미연결

저널은 미라클모닝 시트(시트2)에 날짜순으로, 가계부는 ⭐나의가계부⭐의 월별 탭(예: 2026.09) 마지막 기록 아래에 자동으로 들어가요.

  1. script.google.com에서 프로젝트 “미라클모닝 앱 시트연동” 열기 (없으면 새 프로젝트)
  2. 기존 내용 지우고 아래 코드 붙여넣기 (아래 복사 버튼) → 💾 저장
  3. 우측 상단 배포 → 새 배포 → 톱니바퀴에서 웹 앱 선택
  4. 다음 사용자 인증 정보로 실행: 나 / 액세스 권한: 모든 사용자 (⚠️ “나만”으로 하면 기록이 안 들어가요) → 배포 → 구글 계정 권한 허용
  5. 나오는 웹앱 URL(…/exec 로 끝남) 복사 → 위 칸에 붙여넣고 저장 → 연결 테스트
  6. 스크립트를 고친 뒤엔 배포 관리 → ✏️ 편집 → 버전: 새 버전으로 다시 배포해야 반영돼요
